## 2026-08-06 업무 기록

### 프로젝트

- 제조 표준서 데이터 관리 기능 개선

### 수행 작업

- 화면별 Typed DataSet 생성 위치를 점검하고, 실제 생성 타입을 기준으로 그리드 바인딩 대상을 정리했다.
- 여러 화면 슬롯에 의존하던 상세 데이터 연결 방식을 원본 선택 코드 중심으로 재구성했다.
- 선택형 상세 영역은 선택 여부에 따라 부모와 상세 데이터를 함께 생성하도록 조건을 정리했다.
- 작업 조건과 하위 상세 데이터가 공통 식별자로 연결되도록 저장·조회 흐름을 검토했다.
- 임시 저장과 조회 과정에서 부모 데이터, 상세 데이터, 화면 상태를 복원하는 기준을 점검했다.

### 기술 적용

- C# WinForms / Typed DataSet / DataTable 바인딩
- SQL Server / Table-Valued Parameter / MERGE
- 부모-자식 키 설계와 화면 상태 복원
- 임시 데이터 관리 및 데이터 무결성 검토

### 결과

- 원본 데이터 식별자를 기준으로 여러 상세 영역을 연결하는 저장 구조를 정리했다.
- 선택하지 않은 선택형 영역의 불필요한 데이터 생성을 방지했다.
- 저장 후 재조회와 재저장 시 필요한 코드 복원 지점을 확인했다.

### 다음 작업

- 원본 선택 변경 시 이전 임시 상세 데이터가 남지 않도록 저장 정책을 보완한다.
- 부모 데이터 검증과 개정 이력 조회 조건을 추가 점검한다.
