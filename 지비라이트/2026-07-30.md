## 2026-07-30 업무 기록

### 프로젝트

- 지비라이트 제조 관리 화면 개선

### 수행 작업

- 여러 제조 문서 화면에서 단위별 중량 계산 규칙을 공통으로 적용할 수 있도록 이벤트 기반 재계산 흐름을 점검했습니다.
- 기준값과 단계별 비율 규칙을 분리해 복합 계산이 일관되게 갱신되도록 설계했습니다.
- 숫자 입력과 자동 계산 결과를 소수점 셋째 자리 및 천 단위 구분 형식으로 표시하는 방식을 정리했습니다.
- 데이터 바인딩 그리드의 정렬, 행 추가·삭제, 필수값 검증 동작을 분석했습니다.
- 문서 상태에 따라 편집 가능한 항목과 읽기 전용 항목을 분리하고, 상태별 색상 표시 기준을 적용했습니다.

### 기술 적용

- C# WinForms DataGridView 이벤트 처리
- 데이터 바인딩과 원본 행 식별 관리
- 이벤트 재진입 방지 및 일괄 재계산
- 반올림 및 숫자 표시 형식 제어
- 필수 입력값 검증과 상태 기반 UI 제어

### 결과

- 사용자 중량 변경 시 관련 계산값을 함께 갱신할 수 있는 공통 처리 기준을 마련했습니다.
- 그리드 정렬 상태에서 화면 인덱스와 원본 데이터 인덱스를 혼용할 때 생길 수 있는 오류를 식별했습니다.
- 편집 가능 여부와 필수 입력 여부를 시각적으로 구분하는 UI 기준을 정리했습니다.

### 다음 작업

- 정렬 상태에서도 안전한 행 삭제 처리 반영
- 필수값 검증 및 상태별 편집 제어 통합 테스트
