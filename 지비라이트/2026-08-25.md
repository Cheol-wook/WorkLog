## 2026-08-25 업무 기록

### 프로젝트

- 지비라이트
- 제조 문서 관리 및 공통 결재선 설정 기능

### 작업 목표

- 제조 문서의 신규 정보가 저장·확정·이력 조회까지 일관되게 유지되는 경로를 점검했다.
- 화면과 사용자별 기본 결재선을 문서 처리와 분리해 관리하는 공통 구조를 설계했다.

### 수행 작업

- 제조 문서 기본정보의 신규 텍스트 항목이 작성중, 확정본, 개정 이력에 모두 반영되도록 저장·확정·조회 경로를 분석했다.
- 확정 처리 중 기존 상세 데이터의 일부 수정값이 최신본에 반영되지 않을 수 있는 누락 항목을 확인했다.
- 사용자별 기본 결재선 설정 테이블을 공용 데이터 카탈로그에 등록하고, 식별 키와 적용 범위를 문서화했다.
- 개인 설정이 없을 때 공용 기본 설정을 조회하는 우선순위 기반 조회 방식을 설계했다.
- 데이터 접근 공통 함수의 타입 불일치 원인을 확인하고 프레임워크 요구 타입에 맞추는 방향을 정리했다.

### 기술 스택 및 키워드

- C#, WinForms, 공통 데이터 접근 계층
- Microsoft SQL Server, Stored Procedure, MERGE, 트랜잭션
- 문서 버전관리, 임시본·확정본·이력 데이터 생명주기
- 사용자별 설정, 공용 기본값 fallback

### 결과

- 문서 데이터의 저장·확정·이력 조회 단계별 반영 지점을 정리했다.
- 결재선 설정을 문서 저장 흐름과 독립적으로 관리하는 공통 설계 방향을 확정했다.
- 다음 단계에서 공통 조회 및 즉시 저장 기능을 화면에 연결할 수 있는 기반을 마련했다.

### 다음 작업

- 기본 결재선 조회와 즉시 저장 공통 함수를 구현하고 화면 입력 컨트롤에 연결한다.
- 제조 문서의 신규 정보 항목에 대해 신규 저장, 개정, 확정, 이력 조회 시나리오를 검증한다.
