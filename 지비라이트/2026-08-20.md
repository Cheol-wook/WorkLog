## 2026-08-20 업무 기록

### 프로젝트

- 제조 관리 업무 시스템 개선
- 배합표 목록 및 상세 그리드 상태 관리

### 작업 목표

- 저장 이후 사용자가 작업한 목록 항목을 안정적으로 유지한다.
- 그리드 입력과 행 삭제 상황에서 데이터 입력 가능 상태를 보장한다.

### 수행 작업

- 목록 재조회 후 선택 항목을 식별값으로 복원하는 흐름을 점검했다.
- 선택 상태가 기본 행으로 돌아가는 조건과 상태값 관리 위치를 분석했다.
- 목록 이벤트의 재진입 방지 및 비활성화 처리 위험을 검토했다.
- 그리드 입력 중 값이 덮어써지는 현상의 원인 후보를 이벤트와 데이터 갱신 흐름으로 좁혔다.
- 모든 행이 삭제된 상황에서도 신규 입력 행을 제공하는 처리 방향을 설계했다.

### 기술 스택 및 키워드

- C# WinForms
- DataGridView 이벤트 및 편집 상태 관리
- DataTable 행 상태 관리
- UI 재진입 방지

### 문제 해결

- 정렬된 목록에서는 행 번호가 아닌 식별값으로 대상 행을 복원해야 함을 재확인했다.
- UI 전체 비활성화는 조기 종료나 예외 시 입력 불가 상태를 남길 수 있어 재진입 방지 방식으로 대체하는 방향을 정리했다.
- 삭제 예정 행과 신규 입력 행을 구분해 최소 입력 행을 유지하는 방식을 검토했다.

### 결과

- 목록 선택 복원과 그리드 입력 안정화에 필요한 점검 지점을 정리했다.
- 입력값 손실과 선택 코드 누락의 원인 확인을 위한 다음 디버깅 범위를 확정했다.

### 다음 작업

- 목록 선택 식별값의 저장·복원 흐름을 실제 실행으로 검증한다.
- 그리드 편집 이벤트를 수정해 연속 입력이 유지되도록 처리한다.
- 전체 행 삭제 뒤 기본 입력 행이 생성되는 동작을 구현하고 테스트한다.
