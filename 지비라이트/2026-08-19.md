## 2026-08-19 업무 기록

### 프로젝트

- 제조 관리 업무 시스템 개선
- 배합표 신규 등록 및 목록 조회 화면

### 작업 목표

- 신규 등록 시 이전 문서 상태 정보가 남는 문제를 정리한다.
- 저장 후에도 사용자가 작업하던 목록 항목을 유지하는 조회 흐름을 개선한다.

### 수행 작업

- 신규 등록 화면의 문서 상태 초기화 흐름을 수정했다.
- 목록 조회 결과의 정렬 기준을 이름과 등록 시점 중심으로 정리했다.
- 저장·확정 후 선택한 업무 항목을 식별값으로 다시 찾아 상세 화면을 표시하는 방식을 검토했다.
- 목록 선택 이벤트와 상세 조회가 중복 실행되는 경로를 분석하고 수정했다.
- 제조표준서 데이터 초기화를 위한 테이블 범위와 삭제 순서를 검증했다.

### 기술 스택 및 키워드

- C# WinForms
- DataGridView 선택 및 포커스 관리
- SQL Server 조회 정렬
- 업무 데이터 생명주기 관리

### 문제 해결

- 목록 정렬 이후에는 행 인덱스 대신 업무 식별값으로 대상 행을 복원해야 함을 확인했다.
- 화면 초기화와 상세 데이터 재바인딩의 책임을 분리해, 저장 이후 화면 상태가 불필요하게 사라지지 않도록 개선 방향을 정리했다.
- 상세 조회 중 발생할 수 있는 이벤트 중복 실행과 포커스 해제 가능성을 점검했다.

### 결과

- 신규 등록 시 이전 개정 정보가 남는 문제를 수정했다.
- 목록 재조회 기준과 선택 항목 복원 방식을 정리했다.
- 데이터 초기화 대상과 삭제 순서의 검증을 마쳤다.

### 다음 작업

- 저장·확정·개정 후 목록 선택과 포커스 유지 동작을 실제 화면에서 검증한다.
- 배합표 행 처리 및 불필요한 상태 컬럼 제거 작업을 이어간다.
