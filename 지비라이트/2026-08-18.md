## 2026-08-18 업무 기록

### 프로젝트

- 제조 관리 업무 화면 개선
- 배합표 및 제조표준서 조회 화면 동작 검토

### 작업 목표

- 고객 회의 요청사항을 담당 화면과 공통 개선 과제로 분류한다.
- 목록 조회 화면에서 선택과 상세 조회가 안정적으로 이어지는 방식을 점검한다.

### 수행 작업

- 회의 요청사항을 공통 기능, 설비관리, 배합표, 제조표준서 영역으로 나누어 우선순위를 정리했다.
- 목록 재조회 후 선택 행 복원, 상세 자동 조회, 포커스 유지 흐름을 공통 선행 과제로 정의했다.
- 배합표의 신규 등록 초기화, 행 처리, 이력 및 폐기 조회 관련 후속 항목을 정리했다.
- 목록 그리드의 마우스 드래그 상황에서 상세 조회가 반복될 수 있는 이벤트 처리 차이를 분석했다.

### 기술 스택 및 키워드

- C# WinForms
- DataGridView 이벤트 처리
- 상태 관리 및 포커스 복원
- 업무 화면 UX 개선

### 문제 해결

- 클릭 처리 중 그리드 전체를 비활성화하는 방식은 포커스와 마우스 입력을 불안정하게 만들 수 있음을 확인했다.
- 목록 성격에 따라 콘텐츠 클릭 이벤트 또는 마우스 눌림/해제 기반의 클릭 판별을 적용하는 방향으로 정리했다.
- 저장, 삭제, 재조회 이후에도 사용자가 작업하던 위치를 유지할 수 있도록 선택 인덱스 복원 방식을 검토했다.

### 결과

- 화면별 요청사항과 공통 선행 작업의 처리 순서를 확정했다.
- 목록 선택과 상세 조회가 반복 실행되는 문제의 원인 후보 및 대응 방향을 정리했다.

### 다음 작업

- 배합표 신규 등록 시 이전 개정정보가 남는 초기화 흐름을 수정한다.
- 조회 그리드의 선택 이벤트와 편집 가능 상태를 화면별로 점검한다.
