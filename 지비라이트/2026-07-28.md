## 2026-07-28 업무 기록

### 프로젝트

- 지비라이트 제조 기준 정보 관리 기능 개선

### 수행 작업

- 문서형 기준 정보에 분류값을 추가하고, 임시 저장, 확정, 개정 시작, 상세 조회 흐름 전반을 점검했다.
- 화면 초기화 시 사용자 정의 코드에서 공정 기본값을 불러오도록 구성했다.
- 공정 수가 가변적인 경우에도 고정된 화면 구조가 유지되도록 빈 값 처리 방식을 정리했다.
- 입력 항목과 그리드 데이터의 필수값 검증 방식을 정리했다.
- 수지 데이터에 단위 정보를 추가하기 위한 화면 데이터 전달 및 임시 저장 흐름을 확장했다.
- 확정 시 현재 데이터와 이력 데이터에 새 속성을 함께 반영할 수 있도록 변경 위치를 분석했다.

### 기술 및 설계

- 사용자 정의 코드 기반 기본값 구성
- 임시 데이터, 확정 데이터, 개정 이력 간 일관된 속성 전달 설계
- 테이블 형식 매개변수를 활용한 다중 그리드 저장 구조
- MERGE 기반 저장 및 필수값 검증
- 데이터 모델 확장 시 저장, 확정, 개정, 조회 흐름을 함께 점검하는 변경 절차

### 결과

- 분류값과 공정 기본값을 화면 및 저장 흐름에 연결할 기반을 마련했다.
- 수지 단위 정보의 입력 및 임시 저장 연결을 완료했다.
- 다음 작업에서 확정, 개정, 조회까지 동일 속성을 일관되게 확장할 범위를 정리했다.

### 다음 작업

- 다른 제조 기준 정보 화면에 동일한 데이터 확장 적용
- 분류값 및 단위 정보의 통합 시나리오 테스트
