## 2026-07-29 업무 기록

### 프로젝트

- 지비라이트 제조 관리 화면 개선

### 수행 작업

- 여러 상세 그리드의 임시 저장 방식을 검토하고, 화면의 현재 상태를 기준으로 데이터를 교체 저장하는 방향을 정리했습니다.
- 데이터 재생성 과정에서도 최초 등록 이력은 보존하고 수정 이력만 갱신하도록 감사 정보 처리 기준을 설계했습니다.
- 바인딩 그리드의 행 추가와 정렬 상태가 충돌하는 원인을 분석하고, 데이터 원본과 화면 정렬을 분리해 다루는 방향을 확인했습니다.
- 수식 기반 중량 계산 기능을 기존 단일 비율 계산에서 두 가지 비율 규칙으로 확장했습니다.
- 단위 코드 매핑 오류로 특정 계산 규칙이 실행되지 않던 원인을 찾아 수정 방향을 확인했습니다.
- 계산 결과의 소수점 표시 자릿수를 일관되게 유지하는 방식을 정리했습니다.

### 기술 적용

- SQL Server 트랜잭션 기반 일괄 저장
- TVP 기반 그리드 데이터 전달
- 부모-자식 데이터 정합성 검증
- 데이터 바인딩과 정렬 상태 분석
- 이벤트 기반 재계산 로직
- 반올림 및 숫자 표시 형식 제어

### 결과

- 행 식별값이 변경되는 상황에서도 이전 데이터가 남지 않도록 상세 저장 정책을 명확히 했습니다.
- 최초 등록정보와 수정정보를 분리해 관리하는 기준을 마련했습니다.
- 단계별 계산 규칙과 재계산 순서를 정의해 복합 비율 계산을 확장할 기반을 확보했습니다.

### 다음 작업

- 부모 데이터의 화면 상태 동기화 범위 결정 및 구현
- 신규 단위 규칙과 기존 데이터의 호환성 테스트
- 그리드 정렬 상태에서의 행 추가 동작 확정
