## 2026-08-28 업무 기록

### 프로젝트

- 지비라이트
- 제조 문서 결재선과 배합표 관리 화면 개선

### 작업 목표

- 문서 버전과 연계되는 결재선 저장·조회 흐름을 안정화했다.
- 배합표 입력 규칙과 조회 그리드 정렬 동작을 개선할 방향을 점검했다.

### 수행 작업

- 문서별 결재선을 버전 단위로 관리하는 저장 및 조회 공통 기능을 정리했다.
- 초도 작성, 개정 진행, 확정 문서 상태별로 결재선을 저장하고 조회하는 버전 기준을 설계하고 적용했다.
- 개정 시작 시 기존 화면의 결재선 값을 다음 버전에 저장하도록 연결했다.
- 배합표의 단위별 중량 계산 규칙을 검토하고, 일반 백분율 단위의 기본값 및 계산 제외 규칙을 정리했다.
- 신규 행 생성 시 수치 입력값의 기본값을 설정하는 방식을 정리했다.
- 조회 그리드의 정렬 초기화 오류 원인을 분석하고, 데이터 바인딩 방식으로 전환하는 방향을 적용했다.

### 기술 스택 및 키워드

- C#, WinForms, DataGridView, DataTable 데이터 바인딩
- Microsoft SQL Server, Stored Procedure, MERGE
- 문서 버전 관리, 결재선 관리, 제조 배합 계산

### 문제 해결

- 문서 확정 후 결재선이 조회되지 않는 문제를 버전 상태별 저장·조회 기준으로 분리해 해결했다.
- 개정 과정에서 결재선을 중복 복사하지 않고, 다음 문서 버전에 직접 저장하는 방식으로 흐름을 단순화했다.
- 수동으로 행을 구성하던 조회 그리드가 공통 정렬 초기화 기능과 맞지 않는 원인을 확인하고 바인딩 기반 구조로 개선했다.

### 결과

- 결재선 반영 흐름을 적용하고 정상 동작을 확인했다.
- 배합표 단위와 중량 계산에 대한 후속 구현 기준을 마련했다.
- 조회 그리드 정렬과 선택 복원 테스트를 위한 바인딩 전환 작업을 진행했다.

### 다음 작업

- 배합표 상세 조회의 숫자형 순번 변환 호환성을 보완한다.
- 조회 그리드의 정렬 초기화, 선택 복원, 신규 행 기본값을 화면에서 검증한다.
- 단위 변경에 따른 중량 및 백분율 계산 시나리오를 테스트한다.
