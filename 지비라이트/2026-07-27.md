## 2026-07-27 업무 기록

### 프로젝트

- 지비라이트 제조표준서 관리 기능
- 제조표준서 분류 정보와 팝업 그리드 사용성 개선 준비

### 작업 목표

- 제조표준서 유형을 구분하는 분류 정보를 데이터 구조에 반영
- 팝업 그리드 개편 과정에서 필요한 바인딩 및 선택 동작 기준 정리

### 수행 작업

- 현재본, 작성·개정 중 작업본, 확정 이력본의 기본정보 구조에 공통 분류 필드를 반영했다.
- 테이블 정의 원본과 빠른 조회용 구조 카탈로그를 함께 갱신하고 무결성을 검증했다.
- 데이터 바인딩된 그리드의 안전한 초기화 방식과 셀 단위 선택 설정 방식을 정리했다.
- 다음 구현 우선순위를 일반 제조표준서의 분류 등록 및 조회 기능으로 결정했다.

### 기술 스택 및 키워드

- C# WinForms
- DataGridView 데이터 바인딩
- SQL Server
- 임시본·현재본·이력본 데이터 모델
- 스키마 카탈로그 및 SHA-256 무결성 검증

### 문제 해결

- 바인딩된 그리드에서 직접 행을 삭제하면 제어 오류가 발생할 수 있어, 바인딩 원본 데이터를 초기화하는 방식으로 기준을 정리했다.
- 원본 스키마와 구조 카탈로그가 분리되어 있어 발생할 수 있는 정보 불일치를 방지하기 위해 두 표현을 함께 갱신했다.

### 결과

- 제조표준서 분류 정보를 전체 문서 생명주기에 보존할 수 있는 데이터 구조 기반을 마련했다.
- 스키마 정의와 카탈로그의 일관성을 확인했다.
- 실제 화면 등록·조회 연동과 통합 테스트는 다음 작업으로 남아 있다.

### 다음 작업

- 일반 제조표준서 화면에 분류 코드 선택 및 저장 기능 추가
- 분류 정보를 목록·상세·개정 이력 조회에 반영
- 팝업 그리드 개편 완료 후 화면 동작 점검
