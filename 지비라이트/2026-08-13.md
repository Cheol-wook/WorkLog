## 2026-08-13 업무 기록

### 프로젝트

- 제조표준서 조회 및 작업조건 연동 기능 개선

### 수행 작업

- 상세 조회 결과에서 문서 버전 정보를 유지해 후속 출력 기능에 활용할 수 있도록 조회 흐름을 점검했다.
- 현재 문서와 개정이력 선택 시 서로 다른 경로로 버전 정보를 갱신하는 방식을 정리했다.
- 선택형 작업조건 데이터의 팝업 조회, 결과 전달, 임시 저장 흐름을 분석했다.
- 기존 선택값과 저장 키 형식이 바뀌었을 때 발생하는 중복 등록 가능성을 확인하고, 선택 데이터 전체 교체 방식으로 정리했다.
- 공통 리버스롤 게이지 팝업의 조회 모드와 편집 모드 동작을 검토했다.

### 기술 적용 및 문제 해결

- SQL Server 조회 결과와 C# 전역 상태를 연결해 문서 버전 정보를 관리하는 흐름을 구성했다.
- 부모-상세 데이터가 동일한 선택 식별값을 사용하도록 데이터 전달 경로를 점검했다.
- 팝업의 조회 원본과 편집 가능 여부가 하나의 플래그에 연결된 구조를 분석했다.
- 원본 작업조건은 읽기 전용으로 조회하고, 선택 결과만 제조표준서에 반영하도록 역할을 분리했다.

### 결과

- 문서 버전 정보를 화면 상태에 보관할 수 있는 조회 구조를 확인했다.
- 작업조건 선택값 변경 시 이전 데이터가 남는 문제의 원인과 처리 방향을 정리했다.
- 공통 팝업을 수정하지 않고 부모 화면의 조회 플래그만으로 읽기 전용 선택 흐름을 적용할 수 있게 됐다.

### 다음 작업

- 작업조건 선택부터 저장·재조회까지 통합 시나리오를 검증한다.
- 출력 기능에 문서 버전 정보를 연결해 버전별 데이터 조회를 확인한다.
