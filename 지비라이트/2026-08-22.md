## 2026-08-22 업무 기록

### 프로젝트

- 지비라이트 제조 관리 업무 화면
- 배합 정보, 문서 이력, 제조 기준 정보 입력 기능

### 작업 목표

- 배합 정보의 삭제 및 폐기 조회 흐름을 안정화했다.
- 데이터 구조를 문서화하고, 제조 기준 정보 입력의 누락 원인을 점검했다.

### 수행 작업

- 배합 정보의 현재본, 이력, 임시본과 상세 구성 데이터를 구조화해 내부 카탈로그에 등록했다.
- 업무 데이터와 공통 문서 관리 데이터의 참조 관계를 분석하고, 완전 삭제를 위한 트랜잭션 처리 순서를 설계했다.
- 개정 이력 정렬 기준을 점검해 버전 순서가 일관되게 표시되도록 개선 방향을 정리했다.
- 폐기 상태 문서가 확정 데이터 기준으로 조회되도록 분기 조건을 보완했고, 빈 결과 처리 시 발생할 수 있는 형 변환 오류를 점검했다.
- 선택형 3차 배합 정보가 저장되지 않는 문제를 분석해 화면 상태 초기화로 인한 코드 값 소실을 원인으로 확인했다.
- 수지·코팅·전사 입력 영역을 개별 초기화할 수 있는 공통 리셋 구성 방식을 설계했다.

### 기술 스택 및 키워드

- C#, WinForms, DataGridView, DataTable
- Microsoft SQL Server, 저장 프로시저, 트랜잭션
- 문서 버전 관리, 상태 기반 조회, 데이터 정합성

### 문제 해결

- 폐기 문서가 임시 데이터 경로로 조회되는 문제를 확정 데이터 경로로 통일해 해결했다.
- 선택형 배합 정보 누락은 값 초기화 시점이 저장 흐름과 충돌한 문제로 확인해 수정했다.
- 버전 이력은 날짜보다 버전을 우선하는 정렬 기준을 적용하도록 정리했다.

### 결과

- 배합 정보의 기본 데이터 구조와 문서 연결 관계를 재사용 가능한 형태로 정리했다.
- 폐기 문서 조회와 3차 배합 저장 문제를 해결했다.
- 삭제 및 리셋 기능의 구현·검증 기준을 마련했다.

### 다음 작업

- 완전 삭제 기능을 화면 이벤트와 연결하고 삭제 후 목록 갱신을 검증한다.
- 입력 영역 리셋 후 저장 시 기존 데이터가 정확히 제거되는지 확인한다.
