## 2026-08-21 업무 기록

### 프로젝트

- 지비라이트 제조 관리 업무 화면
- 배합 정보 입력 및 문서 상태 기반 도구 모음 제어

### 작업 목표

- 신규 등록과 삭제 이후에도 안정적으로 입력 가능한 상태를 유지하도록 그리드 흐름을 점검했다.
- 문서 상태에 따라 기능 버튼을 일관되게 제어할 수 있는 기준을 정리했다.

### 수행 작업

- 상세 입력 목록에 유효한 행이 없을 때 기본 입력 행을 보장하는 처리 위치와 조건을 검토했다.
- 저장 후 목록을 다시 조회할 때 방금 저장한 항목을 다시 선택하는 흐름을 분석했다.
- 중복 조회로 인해 선택 상태가 초기화될 수 있는 호출 구조를 확인하고, 저장과 조회의 책임을 분리하는 방향을 정리했다.
- 공통 도구 모음의 비트 기반 활성화 API를 검토하고 문서 상태별 버튼 제어 예시를 설계했다.

### 기술 스택 및 키워드

- C#, WinForms, DataGridView, DataTable
- 상태 관리, 이벤트 처리, UI 선택 복원
- 비트 플래그 기반 권한 제어, 문서 라이프사이클

### 문제 해결

- 신규 저장 후 이전 항목이 선택되는 현상은 저장 코드 반영 전 재조회하거나 재조회가 중복 실행되는 흐름에서 발생할 수 있음을 확인했다.
- 저장 보조 로직은 데이터 저장만 담당하고, 화면 갱신과 선택 복원은 상위 저장 흐름에서 한 번만 수행하도록 분리하는 방향을 결정했다.
- 문서 상태별 기능 제어는 전체 초기화 후 필요한 기능만 개별 활성화하는 방식으로 단순화했다.

### 결과

- 빈 입력 목록, 저장 후 선택 복원, 문서 상태별 버튼 제어에 대한 구현 기준을 정리했다.
- 개별 문서 기능을 조합해 활성화할 수 있는 공통 API 사용 방법을 확인했다.
- 실제 화면 시나리오 테스트와 상태별 권한 확정은 후속 작업으로 남겼다.

### 다음 작업

- 신규 저장 후 선택 복원 및 빈 목록 기본 행 생성 시나리오를 실제 화면에서 검증한다.
- 문서 상태별 도구 모음 정책을 확정하고 각 상세 조회 흐름에 적용한다.
